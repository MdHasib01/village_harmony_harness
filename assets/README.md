# Village Harmony — Assets Directory

This folder contains the master reference media assets for the Village Harmony story studio:

- `logo.png` — Official channel identity logo and studio badge.
- `banner.png` — Channel banner showing the village landscape, hut, hills, and river.
- `raghav.jpeg` (or `Man_wearing_traditional_cotton_k…_20260922195458.jpeg`) — Master character reference for Raghav (mid-30s father, cotton kurta).
- `Woman_wearing_traditional_saree_20260922195500.jpeg` — Master character reference for Gauri (early-30s mother, floral cotton saree).
- `Young_boy_character_description_20260922195455.jpeg` — Master character reference for Aru (7-year-old son, blue shirt, green shorts).

### Background Audio Soundtracks (`assets/audio/`)
- `audio/song-HJG1xIY8TmnYKLOhrZTw.mp4` — Village Harmony Soundtrack #1 (Acoustic bansuri flute, strings, peaceful morning/cooking score).
- `audio/song-KRVBXHvfN395GmuY7y4s.mp4` — Village Harmony Soundtrack #2 (Lively acoustic folk, santoor plucks, playful rhythm).

These assets are statically served when deployed to Netlify and preloaded in the studio interface.
