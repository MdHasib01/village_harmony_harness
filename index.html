Netlify Deployment Architecture

The studio is configured as a zero-build static site ready for instant Netlify hosting. Files in assets/ are automatically served via HTTP.

DIRECTORY STRUCTURE Ready to deploy 
village-harmony-prompt-studio/
├── index.html            # Studio app & UI
├── netlify.toml          # Netlify build config
├── _redirects            # SPA route fallbacks
└── assets/               # Static media folder
    ├── audio/            # Background soundtracks
    │   ├── song-HJG1x... # Soundtrack #1
    │   └── song-KRVBx... # Soundtrack #2
    ├── logo.png          # Channel logo
    ├── banner.png        # World banner
    ├── raghav.jpeg       # Raghav master ref
    ├── Gauri (...).jpeg  # Gauri master ref
    ├── Aru (...).jpeg    # Aru master ref
    └── README.md         # Asset documentation

How to Deploy:

  1. Drag this entire project folder into your Netlify Drop dashboard.
  2. Netlify will instantly publish your site with SSL enabled.
  3. All character images and media in ./assets/ will load automatically without external hosting.
Files netlify.toml and _redirects have been pre-created for you.
